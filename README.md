# Student-Teacher Appointment Booking System

## Technologies Used
- HTML, CSS, JavaScript
- Firebase (Auth + Firestore)

## Features
- Student/Teacher Registration and Login
- Book Appointments with Purpose
- Teacher Views Booked Appointments
- Admin Views All Teachers
- Role-Based Dashboards
- JavaScript Logging
- Firebase Backend

## Deployment
Host using GitHub Pages or Firebase Hosting

## Setup
1. Create Firebase Project
2. Add Firebase Config in `firebase-config.js`
3. Deploy with `firebase deploy` or GitHub Pages
